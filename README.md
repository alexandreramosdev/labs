# 🧪 Labs

Repositório pessoal de experimentos, estudos e testes práticos de programação, com foco em JavaScript moderno (ES6+), conceitos fundamentais da linguagem e padrões de projeto.

## 📁 Estrutura do Projeto

- **`bank.js`**: Implementação de contas bancárias utilizando funções fábrica (*factory functions*), encapsulamento com escopo privado, histórico de transações e prevenção de mutações externas no extrato.
- **`conta-poupanca.js`**: Exemplo prático de herança em JavaScript usando ES6 Classes (`class`, `extends`, `super`), aplicando métodos de saldo e rendimento.
- **`script.js`**: Laboratório de testes abordando conceitos essenciais como Closures, *Temporal Dead Zone* (TDZ), *Hoisting*, *Method Chaining* e o comportamento do operador `this`.
- **`aula-classes-javascript.md`**: Anotações e resumo teórico sobre a transição de Funções Fábrica para Classes ES6 e Protótipos.

## 🚀 Como Executar

Para executar qualquer um dos scripts em JavaScript, certifique-se de ter o [Node.js](https://nodejs.org/) instalado e execute no terminal:

```bash
node nome-do-arquivo.js
```

Exemplo:
```bash
node bank.js
node conta-poupanca.js
```
